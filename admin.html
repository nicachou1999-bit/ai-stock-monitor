還沒有金鑰？建立步驟（約 3 分鐘）
  1. 開啟 GitHub 建立金鑰頁。
  2. Token name 自訂（例：stock-admin），Expiration 選 1 year。
  3. Repository access 選 Only select repositories，勾選 ai-stock-monitor。
  4. Permissions 的 Repository permissions：Contents 設 Read and write，Actions 設 Read and write。
  5. 按 Generate token，複製 github_pat_ 開頭的整串，貼到上面。
